# Amazon Data Protection Policy — compliance matrix for NivaDesk (2026-09-05)

Section by section against Amazon's Data Protection Policy (DPP, as published
for Selling Partner API developers, read 2026-09-05). **Status** means what a
reviewer can verify today: *Met* (evidence in the pack), *Met (attested)* (a
practice with a recorded date, not a setting that can be read), *Gap* (not in
place; owner and date given). The network-security question of the refused
application is covered in `amazon-readiness-criteria.md`; this matrix covers
the rest of the policy so the re-application answers every control honestly.
Evidence paths are under `docs/security/` and `docs/security/evidence/amazon/`.
