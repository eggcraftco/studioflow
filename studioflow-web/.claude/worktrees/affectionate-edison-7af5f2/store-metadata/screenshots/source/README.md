# Screenshot sources

Drop the screenshot files here for the 12-language screenshot set.

What to drop:
- **Finished marketing images** (the ones currently on the App Store / Play Store,
  with the caption band + device frame) — used as the design reference to rebuild
  the template pixel-accurately.
- **Raw app screenshots** (plain simulator/device captures without any text band),
  if you have them — these go inside the frames. If you only have the finished
  images, that also works.

Naming: anything readable is fine, e.g. `1-orders.png`, `2-workflow.png` …
matching the caption order in `../captions.en-US.txt`.

Generated localized sets will be written to `../generated/<locale>/`.
