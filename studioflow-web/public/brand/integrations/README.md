# Integration logos

The onboarding "Connect your accounts" grid looks for these files. When one is
missing the tile falls back to the brand's name set in its own colour, so the
grid is never broken — it just looks better with the real mark.

    shopify.svg        Shopify press kit
    woocommerce.svg    WooCommerce / Woo brand assets
    openbanking.svg    Open Banking Limited brand assets (or your provider's)
    chatgpt.svg        OpenAI brand assets

Use each brand's OWN official file rather than a redrawn copy: their guidelines
require the real mark, unmodified, and a hand-traced approximation is both worse
looking and a trademark problem.

Keep them SVG, transparent, and trimmed to the mark — the tile sizes them to
22px tall.
