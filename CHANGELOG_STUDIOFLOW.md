## Current app + backend + web policy decisions

- If Pro/Team subscription expires or is cancelled, the workspace falls back to Free/Demo, not Lite.
- Free/Demo users must still be able to export/download existing orders and data.
- Storage add-ons should support 100 GB and 200 GB in the future.
- Cloud features should remain subscription-based because they create Firebase costs.
- App and web should share the same Firebase backend, plan logic and role permissions wherever possible.
